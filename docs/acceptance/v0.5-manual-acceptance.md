# ZzClawTerm v0.5 人工验收清单

> 覆盖 M22（OSC 8 可点击超链接）：ZzTermCore 引擎侧（解析/存储/id= 关联/
> reflow 存续/LRU 池）已随子模块 63c93ac 落地并经引擎单测钉住；本清单
> 验收 ZzCoreTerminalWidget 前端交互（M22b）：Ctrl+悬停下划线/手型/
> tooltip、Ctrl+点击打开、同 id 关联段高亮、设置开关。
> 任何一项不通过即打回，修复后复测。

## 1. 基本链接交互

- [x] 本地会话执行
      `printf '\e]8;;https://www.example.com\e\\example链接\e]8;;\e\\\n'`
- [x] 按住 Ctrl 悬停链接文本：显示下划线、光标变手型、tooltip 显示完整
      URI（https://www.example.com）
- [x] Ctrl+点击链接：默认浏览器打开 https://www.example.com
- [x] 松开 Ctrl：下划线与手型消失，tooltip 关闭
- [x] 鼠标移出窗口：hover 态清理（tooltip 不留残影）

## 2. 折行与跨段关联

- [x] 长 URL（超过屏宽折行，`printf '\e]8;;<长URL>\e\\<长文本>\e]8;;\e\\\n'`）：
      Ctrl 悬停任一段，所有折行段一起画高亮底色
- [x] 同 id 两段链接（`printf '\e]8;id=x;https://a.com\e\\甲\e]8;;\e\\ \e]8;id=x;https://a.com\e\\乙\e]8;;\e\\\n'`）：
      悬停「甲」时「乙」同步高亮，反之亦然

## 3. 设置开关

- [x] 设置页「超链接：启用可点击超链接 (OSC 8)」默认勾选
- [x] 取消勾选后：Ctrl+悬停无下划线无手型无 tooltip；Ctrl+点击无反应
      （走原选区逻辑）
- [x] 重新勾选后功能恢复；重启程序后开关状态持久（settings.ini
      terminal/hyperlinkEnabled）

## 4. 安全与兼容

- [x] scheme 白名单外链接（如 `file://` 在名单内可开；`javascript:` 或未知
      scheme）Ctrl+点击不打开任何程序，仅忽略
- [x] SSH 远端会话输出链接（coreutils ≥ 8.32 可 `ls --hyperlink=auto`，
      或直接 printf 同上序列）：本地浏览器打开
- [x] resize 缩列扩列后链接仍可点、hover 仍命中（reflow 存续）
- [x] 不换行模式（Ctrl+Shift+U）下横向滚动后链接命中位置正确
- [x] 上滚进入历史区后，历史行中的链接同样可 hover/点击

## 5. 回归（不按住 Ctrl 时与 v0.4 完全一致）

- [x] 普通拖选、复制粘贴内容正确
- [x] Ctrl+点击落在非链接格：照常启动选区
- [x] vim/less 全屏程序交互正常（Alternate 屏无历史，无链接残留）
- [x] 搜索、配色切换、字体缩放（Ctrl+滚轮）不受影响
