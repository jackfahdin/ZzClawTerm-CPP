# ZzClawTerm v0.4 人工验收清单

> 覆盖 v0.3.0 之后的四轮变更：Stacked 中央工作区切换、ZzTermWidget 摘除
> （终端链路全部走 ZzCoreTerminalWidget + ZzTermCore）、ZzPureTools 升级
> （新 QWindowKit 窗口链路）、Windows 预设 Ninja+cl 切换；
> 并收口 Z3 收官时遗留的手测项。任何一项不通过即打回，修复后复测。

## 1. 终端基础回归（ZzTermWidget 摘除后）

- [ ] SSH 会话连接、交互、断连重连正常
- [ ] 本地会话（local shell）正常：启动、输入、Ctrl+C 中断、退出
- [ ] vim 全屏编辑正常（打开、编辑、保存退出、方向键）
- [ ] `ls` 多栏输出、长输出滚动、`clear` 清屏行为正常
- [ ] 选区复制：鼠标拖选、复制粘贴内容正确
- [ ] 搜索（快捷键唤起）定位与跳转正常

## 2. Stacked 中央工作区

- [ ] 新建/关闭标签页正常，标签标题跟随会话状态
- [ ] 分屏（Ctrl+Shift+E/O）在 Stacked 工作区下各窗格独立正常
- [ ] 侧栏/面板显示隐藏切换正常，窗口重开布局恢复
- [ ] 窗口标题真实生效（系统任务栏/标题栏显示会话标题）

## 3. 配色与编码

- [ ] 全局配色切换立即生效到所有会话
- [ ] 会话级配色覆盖全局值；切回「跟随全局」后跟随全局（Z3 任务 1 口径）
- [ ] 会话级编码（GBK）会话收发中文不乱码（Linux 端先验，Windows 见 §7）

## 4. 宽字符与中文显示

- [ ] **复测**：中文显示完整（v0.3 手测曾出现"中文只显示一半、选中后全显"，
      若复现则转 bug 修复，不算通过）
- [ ] 80 列屏连续敲 40 个汉字，行尾光标不盖字形右半
- [ ] vim 内中文输入、显示正常

## 5. IME

- [ ] 中文输入法连续上屏，preedit 不丢拍
- [ ] 不换行模式下 preedit 可见

## 6. 滚动与历史（日志完整性修复后重点）

- [ ] 长会话（>10 万行输出）滚到顶继续上滚，逐块加载不错位不重行不丢行
- [ ] 滚动中 resize 后历史不错位
- [ ] 触控板/精密滚轮小步距慢滚不偏钝（无 hi-res 设备则跳过）

## 7. Resize 与缩放

- [ ] 反复拖拽窗口尺寸（含缩窄后拉宽），内容完整无残行、无不换行截断丢失
- [ ] 缩放到很小再最大化，显示恢复满屏
- [ ] 字体缩放（Ctrl+滚轮/快捷键）生效；作用域（当前标签 vs 全局）符合预期
- [ ] 窗口最小尺寸限制下行为确认（程序限制在前，视为通过）

## 8. Windows 实机（换编译器后首次全链路）

- [ ] Ninja+cl 预设构建通过（`windows-msvc-release`）
- [ ] `scripts/package-windows.ps1` 打包出 zip，绿色包解压可运行
- [ ] ConPTY 本地会话：cmd/PowerShell 交互、方向键、vim/编辑器等全屏程序
- [ ] GBK 会话收发中文不乱码（Core5Compat 路径，Z2 遗留项）
- [ ] SSH 会话连接正常（libssh2 新源首次 Windows 实测）

## 9. 性能粗验

- [ ] 大数据量输出（如 `yes` 几秒后 Ctrl+C）界面不卡死
- [ ] 长时间会话内存无异常增长（任务管理器/系统监视器粗看即可）
